L1 — sealed judge (brief 1); released as a digest-pinned image at L2. So far: the OCI runtime abstraction (`runtime.py`, brief 1 §2 and A1 item 2). It builds the one command line that runs a candidate container: `--network=none`, `--read-only` (and Podman's `--read-only-tmpfs=false`, so both runtimes give the same root), `--cap-drop=ALL`, `--security-opt=no-new-privileges`, no mount of any host path, and CPU, memory (swap equal, so none) and process limits from `config.toml`. Docker is admitted only if it reports itself as Docker with a server; Podman only if it is rootless with the cpu, memory and pids controllers delegated. P2 (`harness/pins.py`) runs a probe in that container under every usable runtime and requires at least one. Each denial must be an OS errno: ENOENT or EACCES/EPERM for judge paths, ENETUNREACH for IPv4 and IPv6 TCP and UDP, EROFS for the root. The probe must also see only loopback and the configured cgroup limits.
